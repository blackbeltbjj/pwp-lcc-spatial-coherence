# Variable Dictionary

A_can
Canonical threshold-exceedance Pacific Warm Pool area.

A_LCC
Area of the daily largest connected component.

A_sec
Secondary area:
A_can - A_LCC.

f_LCC
Connected fraction:
A_LCC / A_can.

F
Fragmentation index:
1 - f_LCC = A_sec / A_can.

N_c
Number of daily eight-neighbor connected threshold-exceeding components.

Detached occurrence
Fraction of valid SST days for which a cell satisfies the canonical
temperature threshold but does not belong to the daily LCC.

LCC occurrence
Fraction of valid SST days for which a cell belongs to the daily LCC.

Longest continuous LCC membership
Maximum uninterrupted run of days during which a cell remains in the LCC.

Canonical-LCC centroid distance
Great-circle distance between area-weighted spherical centroids of the
canonical threshold domain and the LCC.

Thresholds
28.0 C, 28.5 C and 29.0 C.

Annual trend sample
44 complete calendar years, 1982-2025.
